# LEANODM 玩具与收藏品页设计规格

日期：2026-09-28

页面：`/products/toys/`

导航名称：Toys & Collectibles

状态：设计审核稿。当前只设计这一页面，用户审核后才进入下一个品类。全站头脑风暴继续，不启动具体文案、实施计划或代码工作。

依据：[全站架构](2026-09-28-leanodm-site-architecture-design.md)、[首页](2026-09-28-leanodm-home-design.md)、[产品概览](2026-09-28-leanodm-products-overview-design.md)，以上均已批准，含夜灯降级为补充应用的修订。

本文件的模块名称、字段和问题主题用于设计。仅第 5 项提供用户要求的建议 H1，不撰写正文、SEO 元描述、新 CTA 文案或完整 FAQ 答案。

## 设计方向与产品边界

推荐建立可独立承接采购访问的玩具与收藏品分类页：产品方向与真实实例先出现，接着说明定制范围、合作起点以及对应制造和质量实证。

| 方案 | 取舍 |
| --- | --- |
| 产品实例＋定制范围＋针对本类产品的交付证据（推荐） | 兼顾品类搜索、产品判断、工程与质量审查以及项目咨询 |
| 单纯按型号排列的目录 | 适合寻找现成型号，但难以说明新产品开发与成熟设计 OEM 的合作范围 |
| 完整复制工厂与服务总览 | 能介绍很多能力，但削弱玩具采购意图，和首页、制造及服务页面重复 |

产品方向采用以下层级。这是本页浏览结构，尚不新增其他子品类路由：

| 浏览方向 | 展示范围与位置 | 页面关系 |
| --- | --- | --- |
| 收藏玩偶与角色模型 | 第一产品方向，呈现实际塑胶玩偶、模型或收藏产品实例 | 对接已规划的 `/products/toys/collectible-figures/`；本轮不设计该子页 |
| 塑胶玩具与可选电子功能 | 展示实际产品的结构、玩法和功能差异；电子功能作为可选能力，普通塑胶项目同样适配 | 先作为本页展示组，连接已有或后续设计的唯一产品详情，不批量增设子分类 |
| 毛绒相关应用 | 在上述方向后以补充实例说明实际承担的塑胶部件、电子模块或组合开发工作 | 不从塑胶/电子能力推断完整毛绒裁剪缝制业务；使用实际项目范围 |

纪念品及品牌商品按主要采购用途与 Gifts 页面交叉关联。侧重角色、收藏或玩耍的内容由 Toys 深入解释；侧重文创、纪念或品牌商品项目的内容由 Gifts 解释。同一产品只有一个主详情 URL，可以跨栏目推荐。

POP MART 等在原始需求中的品牌例子只帮助理解产品方向，不转化为客户、合作关系、授权款式或本站关键词策略。夜灯不作为本页产品方向或主要案例。

## 1. 搜索意图

寻找能够按要求开发或制造塑胶玩具、收藏玩偶以及带可选电子功能玩具的 OEM/ODM 工厂。

买家需要确认：

- 是否覆盖自己的产品形态及工程要求。
- 能从已有产品、参考样品、角色概念或成熟设计的哪一步开始合作。
- 外观、结构和功能要求怎样在样品与量产中确认。
- 是否有可比较的实际产品、过程和检验依据。

本页是制造合作的商业意图页面，不以消费者购买单件玩具为任务，也不试图覆盖所有材料、年龄与玩具类型。

## 2. 目标买家

- 玩具品牌与收藏品品牌的采购及产品开发负责人。
- 自有角色或合法授权项目的产品团队。
- 需要按图生产、改款或开发专属产品的国际品牌及采购组织。
- 参与结构、电子方案、量产验收和供应商审核的工程及质量人员。

页面对已有成熟设计和仍处于概念阶段的项目提供不同入口，不要求买家从公开现款中挑选后才能咨询。客户规模与项目适配通过需求和合作条件判断，不用大客户 Logo 代替技术与质量信息。

## 3. 主要 SEO 关键词／主题

主要主题：**定制塑胶玩具与收藏品的 OEM/ODM 制造**。

主要候选词：`custom plastic toy manufacturer`。

相关主题：plastic toy OEM/ODM、custom toy manufacturing、toys and collectibles manufacturing。收藏玩偶的具体词组由已规划的 `/products/toys/collectible-figures/` 进一步承接；本页保留摘要与入口。

用上述候选词进行的公开搜索可见供应商自有网站中的定制制造与 OEM/ODM 意图。这仅支持用语与采购意图判断，不代表已验证搜索量、竞争难度、排名或获客规模。关键词数据评估后续进行，不影响本轮结构设计。

| 页面 | 主题分工 |
| --- | --- |
| `/products/` | 全部产品领域的导览与适配入口 |
| `/products/toys/` | 塑胶玩具与收藏品的整体开发制造需求 |
| `/products/toys/collectible-figures/` | 收藏玩偶/角色模型的深入产品问题 |
| `/products/[product-slug]/` | 单一产品或方案的具体信息及项目条件 |
| `/products/gifts/` | 礼品、文创与品牌商品采购任务 |
| `/customization/` 及服务路径 | 各项目阶段的合作方法与交付边界 |

面向搜索与 AI 阅读的内容包括：明确产品名称、制造角色、可调整项、项目适用条件以及关联证据；重要信息使用可读取的正文，不只存在于图片或折叠交互中。同一事实不通过不同关键词版本复制多套页面。

## 4. 页面目标

主要目标：获得带有玩具产品背景的合格项目咨询。

辅助目标：让买家进入合适的子品类或产品详情，理解相关服务路径，继续查看质量及制造资料。

本页的目标比产品总览更接近实际项目评估：总览帮助找到领域，本页帮助判断这一类项目是否值得交由 LEANODM 评估。

未来观察品类/详情访问、服务路径选择、携带玩具上下文的项目提交及需求完整度。此处不设无基线的转化百分比，也不将资料浏览和按钮点击直接当作有效询盘。

## 5. 建议 H1 标题

**Custom Plastic Toys & Collectibles: OEM & ODM Manufacturing**

首屏内容要求：面包屑 Home → Products → Toys & Collectibles；H1；范围简述；实际代表产品图；全站项目 CTA 及进入产品方向的浏览动作。具体短文案留至文案阶段。

首屏以产品识别为主，不用通用仓库图、未经授权的品牌视觉或夜灯项目主图。产品照片可以同时呈现多个代表实例，但需能辨认外观和结构。

## 6. 版块顺序

1. 玩具与收藏品制造定位及代表图。
2. 产品方向与实际实例。
3. 可定制内容与工程适配。
4. 合作起点：现款、改款、概念开发与成熟设计 OEM。
5. 与玩具项目对应的制造、质量及精益实践。
6. 玩具或收藏品项目案例摘要。
7. 本品类采购问题与需求准备。
8. 项目咨询入口。

产品实例先于通用工厂介绍；品质与精益证据连接具体产品要求；完整设备清单、开发流程和质量体系仍由专题页面承担。

## 7. 所需内容

| 模块 | 必需内容字段 | 呈现边界 |
| --- | --- | --- |
| 制造定位 | 产品范围、OEM/ODM 属性、实际代表图与下一步 | 简短说明，避免重复首页公司故事 |
| 产品方向与实例 | 浏览方向、代表产品、主要特点、实际承担工作、详情/子品类入口 | 收藏玩偶优先；塑胶与电子功能实例随后；毛绒相关项目为补充。卡片标明现款或项目案例性质 |
| 可定制内容 | 造型/尺寸、材料评估、颜色与印刷、结构装配、可选电子功能、包装要求 | 按产品需要选择；说明哪些属于外观调整、哪些可能需要工程或模具变更，不给所有产品相同选项 |
| 合作起点 | 买家已有资料、对应服务、需要补充的信息、服务链接 | 使用紧凑对应表，不重新展开完整 ODM 流程 |
| 制造、质量与精益 | 实际产品要求、对应工艺、控制节点、验证记录、相关改善实践 | 采用产品要求到过程证据的对应关系，不堆砌设备或认证 Logo |
| 项目摘要 | 客户需求、实际角色、主要难点、样品/过程确认、结果及案例入口 | 选择 1–2 个相关玩具/收藏品项目；不使用夜灯代替本类产品经验 |
| 采购问题 | 起订与模具投入的影响因素、打样确认、颜色/版本与验收、资料准备、目标市场与使用对象、知识产权及保密流程 | 只确定问题主题与所需回答信息，本轮不撰写 FAQ 答案 |
| 项目咨询 | 进入 Contact 的动作及需求准备提示 | 复用全站 CTA，不在本页增加完整表单或附件上传 |

可定制内容的工程解释采用统一字段：买家想改变什么 → 影响哪些部位或要求 → 如何确认样品/标准 → 对应服务。不得从“模具与注塑”自动扩展为搪胶、滚塑、树脂浇注或其他未确认工法；实际材料与工艺清单在内容整理时依据工厂资料填写。

建议的简短项目输入包括：参考图/样品/图纸的现有状态、用途与预期使用者、尺寸材料要求、是否包含电子功能、目标市场、预计数量、当前阶段和期望上市时间。是否上传文件及其处理方式留给 Contact 页面设计，不在这里收集。

## 8. 所需证据／佐证

用户已确认资料充分，本节仅规定选材用途，不把资料提供设置为设计前置条件。

| 资料 | 买家判断 | 推荐位置 |
| --- | --- | --- |
| 真实玩偶/玩具产品图、样品与基本信息 | 是否有相关产品经验，能达到何种外观与结构要求 | 产品方向与实例 |
| 实际承担的开发/模具/注塑/印刷/装配资料 | 哪些工作由工厂完成 | 产品实例与制造对应说明 |
| 封样、外观判定、装配及功能检验样例 | 样品与量产采用怎样的共同判定依据 | 质量证据单元 |
| 对应项目的物料区分、标准作业、换款确认或过程追溯实例 | 多部件、多版本产品怎样控制混料、错装和过程偏差 | 精益实践单元，按实际已有记录选择 |
| 与具体产品、用途和市场对应的测试记录/报告 | 对哪些要求完成了什么验证 | 质量说明及专题链接 |
| 可公开的脱敏玩具项目 | 实际问题怎样处理，结果如何 | 相关案例摘要 |

检测资料展示应注明对象、范围与时间，不把单个产品的报告描述成全品类认证。页面把预期使用者、材料、功能和目标市场纳入项目需求；不以“收藏品”名称直接推定某类安全要求不适用，也不对所有年龄或市场作统一承诺。这里定义证据呈现方式，具体项目适用要求在工程与测试评估中确定。

工程与质量内容由相应人员审核，公开资料显示适用对象及版本。产品图、工厂数字与案例成果分别保留真实主体；沿用东莞 Xinyinhai 工厂身份，不加入海外工厂或集团合并数字。

## 9. CTA 策略

- 全页主要项目入口复用 **Discuss Your Project** → `/contact/`，携带玩具类别和可选产品/项目阶段上下文。
- 收藏玩偶入口在子页实际可用时进入 `/products/toys/collectible-figures/`；其他实例进入唯一产品详情或相应实际案例。
- 对现款、改款、概念和成熟设计分别链接四条已规划的服务路径；不确定合作方式时允许直接联系。
- 首屏和页尾保留项目动作，产品区以浏览和了解具体产品为主，证据区以查看相关资料为主。
- 分类可以预填，买家仍能更改；不因来源是玩具页而阻止其他塑胶电子需求提交。
- 除全站已有 CTA 外，只规定动作、目的地与上下文，不在此阶段撰写新按钮用语。

## 10. 内部链接策略

| 来源 | 目标 | 作用 |
| --- | --- | --- |
| 面包屑 | `/`、`/products/` | 明确层级并支持返回 |
| 收藏玩偶产品方向 | `/products/toys/collectible-figures/` | 将深入细分需求交给已规划子页；子页完成后才发布链接 |
| 代表产品 | `/products/[product-slug]/` | 查看唯一产品资料；本页只提供概览 |
| 项目样例 | 相应案例页或 `/case-studies/` | 查看实际承担工作与交付结果 |
| 合作起点 | `/customization/existing-products/`、`/customization/product-adaptation/`、`/customization/new-product-development/`、`/customization/oem-manufacturing/` | 按项目阶段继续 |
| 对应制造证据 | `/manufacturing/tooling/`、`/manufacturing/injection-molding/`、实际适用的印刷/电子/装配页面 | 查看相关工序能力 |
| 对应质量证据 | `/quality/appearance-inspection/`、`/quality/in-process-inspection/`、`/quality/product-testing/` | 查看标准及验证方法 |
| 精益实例 | `/lean-manufacturing/` 或相应实践文章 | 了解与产品控制直接有关的管理方法 |
| 礼品或纪念用途 | `/products/gifts/` | 按主要采购任务交叉推荐，避免复制产品正文 |

每个模块选择最相关的少量链接，不把整份全站目录堆在页面中。普通链接与面包屑负责发现，产品字段和说明负责理解；不依赖站内搜索或交互筛选才能找到核心产品。

本轮不设计收藏玩偶子页或产品详情模板。规划中的链接属于将来的内容关系，实际发布不得出现空目标或占位产品。

## 12. 移动端适配考量

- 首屏控制高度，让用户尽早接触产品实例；不依赖全屏视频或自动轮播。
- 产品方向按单列组织，收藏玩偶优先；毛绒相关补充位置保持清晰。
- 产品图展示完整造型与关键部件，文字说明在图片之外；局部细节以可阅读的独立图呈现，不要求悬停。
- 定制范围矩阵和合作起点表转为逐条标签/值，避免横向拖动才能理解。
- 质量及精益证据先给可读取摘要，再进入较大图片或文档；不直接嵌入无法阅读的整页扫描件。
- 品类采购问题可以折叠，产品范围、关键条件和项目入口保持直接可读。
- 使用有明确目标的链接、可见焦点与适当触控区域，复用全站键盘菜单及减少动画规则。
- 点击项目入口保留产品上下文，不跳回无关的空白询盘；不增加遮挡页面的固定浮层。
- 后续实施验收覆盖窄屏与导航切换宽度，检查真实图像裁切、长产品名称、表格转换和键盘操作。本轮不运行页面界面测试。

## 审核标准与阶段边界

本页应让买家判断：产品是否匹配、哪些内容可定制、从哪个项目阶段合作、工厂实际做什么、外观/结构/功能如何确认，以及如何提交项目。

本页只有设计规格，没有生产代码、具体文案或子页面规格。用户批准后，下一页为 `/products/gifts/`；其他品类、产品详情模板及后续栏目继续按既定顺序分别审核。
